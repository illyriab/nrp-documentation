## Abbreviations

| Abbreviation | Meaning                                                                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AAI**      | Authentication & Authorization Infrastructure                                                                                                                        |
| **CCMM**     | Common Core Metadata Model                                                                                                                                           |
| **DOI**      | Digital Object Identifier                                                                                                                                            |
| **EOSC**     | European Open Science Cloud                                                                                                                                          |
| **EOSC CZ**  | Czech national initiative implementing the EOSC                                                                                                                      |
| **FIP**      | Service for FAIR Implementation Profiles development and testing                                                                                                     |
| **L1**       | first-level user support, i.e. the front line answering end users' questions                                                                                         |
| **NKR**      | National Catalogue of Repositories (Národní katalog repozitářů, NKR)                                                                                                 |
| **NMA**      | National Metadata Directory (Národní metadatový adresář, NMA)                                                                                                        |
| **NRP**      | National Repository Platform (Národní repozitářová platforma)                                                                                                        |
| **PID**      | persistent identifier                                                                                                                                                |
| **OS II**    | The Open Science II project supports the construction of the National Data Infrastructure (NDI) and the implementation of the EOSC initiative in the Czech Republic. |
| **RT**       | Request Tracker (ticket‑tracking system)                                                                                                                             |
